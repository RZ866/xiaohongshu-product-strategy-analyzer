# 商品与证据

用户已选一个商品：先按购买任务拆解，而不是先给流量话术。

商品字段至少考虑名称、类目、用途、功能、规格、材质、成本、售价、包装、发货、人群、场景、卖点、资质、售后。输出不必变成问卷，未知字段可以合并说明。确认名称用途后先做场景与执行难度的条件性分析；成本/资质/履约决定经营结论能否成立。

建立Evidence：id、type、source、excerpt；官方规则增加url与checked_at。USER是用户陈述、IMAGE是实际读到的图中文字/外观、OFFICIAL是实际核查的适用官方资料、SAMPLE只可出现在明确demo报告。附带摘录及适用范围，用户陈述不等于独立鉴定。

结论标签：FACT仅复述材料所述；INFERENCE解释意义并注明局限；HYPOTHESIS是待测试方向；UNKNOWN是不能判断。已确认商品规格不能支撑“市场需求旺盛”。图片可见外观不能证明内部材质、安全认证或实际功效。

快速输出新手适配、3优势/3风险（不足明确不足）、人群与内容角度、继续/暂缓理由、3动作、最多3问。停止问题扩张：每个追问须影响当前决策，例如每单实收成本、准入材料、能否履约，避免无关年龄/兴趣问卷。

需要当前规则时提示用户查实际官方商家后台、类目资质与商品发布规则，记录适用日期/类目/资料。没有证据不声称平台允许上架。此文件不给法律或医疗意见。
