# HTML交付

单文件、内联CSS、原生CSS条形图、无CDN/字体请求/JS。CSP禁外部资源与脚本。桌面3列卡片、选题/计划2列，手机1列；打印改连续单列。目录跳转与证据锚点为原生链接，维度详情折叠。打印时确保详情可见；浏览器不支持相关CSS时先展开详情再打印。

首页：商品名、A/B/C/D、理由、最大风险、测试方向与三动作。后续覆盖概览、六维、优势风险、三情景利润、人群、场景、打法、十选题、上架草稿、7天、30天、数据表、行动与证据。评分空值无条形图，不伪装成0分。

图片可选：仅加载输入文件目录内显式指定PNG/JPEG/WebP，检查签名及12MiB上限，内嵌data URI。路径越界、远程URL、SVG或错误文件用占位，不自动下载。复杂畸形图片解码仍由浏览器决定，需实际预览；不宣称图片真实性鉴定。

所有用户文本经html.escape；CSS宽度只来自校验后的数字。输出中文UTF-8；实际打开浏览器检查电脑/手机、证据跳转、中文、打印与安全。没有浏览器能力则如实记录NOT RUN，不把单纯字符串测试当视觉验收。
