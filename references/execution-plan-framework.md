# 7天和30天执行

每项需goal/steps/materials/done/caution以及证据。步骤必须指向具体动作与可见产物，不能只有“优化内容”。action枚举VERIFY/PREPARE/PUBLISH/REVIEW。每项提供blocked_steps与blocked_done：当前门未通过时执行这些替代任务，禁止含直接上架或带货发布动作。

7天默认验证→定位→上架草稿→素材→3篇不同角度稿→条件性发布→复盘；day必须1～7。不因天数到了就跨过样品、资质或成本核验。缺样品先索样，不编拍摄结果。C/D所有天切换核验/整改，仍可完成草稿，不投入库存。

30天覆盖1-7、8-14、15-21、22-30四阶段。准备验证；小规模内容测试；基于真实同窗口数据迭代；决定继续/调整/停止。没出单不等于商品失败，可能尚无足够测试样本；不能编统一CTR淘汰阈值。

表头在data-record.csv：日期、笔记ID、角度、变量、发布数量、曝光、阅读、可得封面点击率、收藏、评论、可得商品点击、咨询、订单、成交额、单笔贡献、实际测试支出、退款损耗、来源口径、窗口、下一步。缺失留空，零只指确实观测到零。互动指标不替代销售，点击率分子分母须来自同口径。

先问可承受损失max_loss和planned_spend；未知不得补造预算。记录累计支出并在达到预算上限时暂停新增投入（保守现金控制，不代表全部支出都成为最终损失）。出现安全/准入/无法履约立即暂停；实际贡献非正先重算；样本不足写未定，不用行业传言判成功。检查下一轮只改变一个主要变量并保留修改记录。
