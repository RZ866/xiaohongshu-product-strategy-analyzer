# 人群、场景、打法与十选题

人群描述须含具体任务、发生场景、顾虑、可能购买理由，不仅是年龄性别。定位差异来自已知属性与可验证服务边界；样本差异不等于全市场独家。

写1主2备场景：场景名、痛点、真实卖点/待验证属性、表达方式、证据。选1主2辅打法并解释why/audience/demonstration/materials/risk。候选为痛点、场景、低价刚需、演示、情绪、季节、送礼、教程；缺低价对照不选“全网低价”，无节日证据不称季节爆发。

深度10选题每项含name/title/pain/angle/cover/structure/placement/purpose/evidence_ids。可覆盖动作痛点、空间场景、操作教程、购买顾虑、替代方案、生活流程、细节规格、数量预算、使用边界、用户问题。选择不适用则换角度；不机械生成同一品名的十个同义句。

语义检查：每篇解决的问题、叙事结构和测试目的至少一项实质不同；主品出现时机与任务可解释。程序只能拒绝完全重复title/angle/purpose，宿主必须人工对照。无亲测则写拍摄方案/待测问题，不写“用了7天”“买家都说”“实测有效”。

上架草稿含主标题+2备选，真实品类/规格/用途；主图视觉、摆放、背景、卖点与禁用宣称；单SKU优先，组合仅适用且核算；价格假设说明；详情按购买理由→场景→特点→参数→说明→注意→售后。不能自动宣称标题符合所有最新平台规则。

C/D下保持明确暂停标识：十选题仅为商品条件改善后的研究草案；负利润产品当前策略应先改成本/定价或换品，高风险产品应先核验资质与安全。禁止一边拒绝一边建议立即发笔记卖货。
